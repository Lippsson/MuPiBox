# Uhrzeit in der Kopfzeile

Die Erweiterung **Uhrzeit in der Kopfzeile** zeigt die Uhrzeit oben im Display, rechts neben der Akkuanzeige. Sie richtet auf der Box nichts ein und braucht kein Zubehör.

Nach der [Installation](installieren.md) stehen ihre Einstellungen in den Details ihrer Karte unter **Einstellungen › System › Erweiterungen**:

| Einstellung | Wirkung |
| --- | --- |
| **Anzeige** | **Digital** (Ziffern) oder **Analog** (ein kleines Zifferblatt) |
| **Format** | **24 Stunden** oder **12 Stunden**. Das Zifferblatt der analogen Uhr hat immer 12 Stunden |

Eine Änderung gilt sofort; das Display lädt dafür kurz neu.

> [!NOTE]
> Die Box hat keine eigene Uhr. Sie holt die Zeit aus dem Netzwerk. Ohne Netzwerk läuft sie mit der zuletzt gespeicherten Zeit weiter und kann deshalb falsch gehen, bis sie wieder online ist.
