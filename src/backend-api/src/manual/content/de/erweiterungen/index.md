# Erweiterungen

Seit MuPiBox 5.1 lassen sich **Erweiterungen** nachinstallieren: Zusatzfunktionen, die nicht jede Box braucht. Die Box bleibt ohne sie vollständig. Installiert, ein- und ausgeschaltet und entfernt werden sie in der App unter **Einstellungen › System › Erweiterungen**.

| Seite | Inhalt |
| --- | --- |
| [Installieren und verwalten](installieren.md) | Katalog, Installieren, Ein- und Ausschalten, Entfernen, eigene Dateien |
| [Buttons & GPIO Input](buttons.md) | Taster an den GPIO-Pins steuern die Box: kurz und lang drücken, Doppeltaster |
| [USB-CD-Laufwerk](cd-laufwerk.md) | Audio-CDs vom USB-Laufwerk abspielen |
| [Uhrzeit in der Kopfzeile](uhrzeit.md) | die Uhrzeit oben im Display, digital oder analog |
| [Wetter](wetter.md) | das Wetter eines Ortes als Messuhren auf dem Display |

> [!WARNING]
> Eine Erweiterung ist ein Programm, das auf der Box **ohne Schutz** läuft. Installiere nur Erweiterungen aus dem Katalog oder aus Quellen, denen du vertraust.
