# Fotos

Die Box zeigt am Display auch Fotos und kurze Videos: als **Alben**, die das Kind selbst öffnet, und auf Wunsch als **Bildschirmschoner**, wenn an der Box eine Weile niemand etwas tut. Für das Anschauen gibt es eine eigene **Bildzeit**, getrennt von der Hörzeit.

Die Fotoanzeige ist anfangs aus. Du schaltest sie unter **Einstellungen › Fotos** ein ([Einschalten und Einstellungen](einschalten.md)).

## Woher die Fotos kommen

| Quelle | Wie | Seite |
| --- | --- | --- |
| **Hochladen** | Fotos und Videos vom Handy oder PC in ein Album der Box | [Fotos hochladen](hochladen.md) |
| **NAS-Ordner** | Ordner vom NAS, mit dem die Box verbunden ist, werden Alben | [NAS-Ordner](nas-ordner.md) |
| **Immich** | Alben eines Immich-Servers im Heimnetz | [Immich](immich.md) |
| **Synology Photos** | Alben aus Synology Photos auf einem Synology-NAS | [Synology Photos](synology-photos.md) |

Alben aus Immich und Synology Photos kann die Box speichern oder beim Anzeigen live holen ([Foto-Dienste: speichern oder live](speichern-oder-live.md)).

## So geht es los

1. **Einstellungen › Fotos** öffnen und **Fotoanzeige** einschalten.
2. In der App unter **Bibliothek › Fotos** auf **Fotos hochladen** tippen oder mit **Foto-Dienst verbinden** eine Quelle einrichten.
3. Am Display erscheint der Reiter **Fotos**, sobald ein Album sichtbar ist ([Fotos am Display](am-display.md)).
4. Unter **Spielzeit › Bildzeit** legst du fest, wie lange am Tag Fotos angeschaut werden dürfen ([Bildzeit](bildzeit.md)).

> [!NOTE]
> Fotos bleiben auf der Box in deinem Heimnetz. Es gibt keine Links zum Teilen. Die Box lädt Fotos nur aus deinem Heimnetz bzw. von den Diensten, die du selbst einrichtest.

Hakt etwas, hilft [Wenn Fotos fehlen](probleme.md).
