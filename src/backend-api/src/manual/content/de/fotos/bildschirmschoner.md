# Bildschirmschoner

Der Bildschirmschoner zeigt eine Diashow aus den sichtbaren Alben, wenn an der Box eine Weile niemand etwas tut. Du schaltest ihn unter **Einstellungen › Fotos › Bildschirmschoner** ein.

| Einstellung | Wirkung |
| --- | --- |
| **Bildschirmschoner** | an oder aus |
| **Startet nach** | nach wie vielen Minuten ohne Berührung (1 bis 30, anfangs 5) |
| **Auch während der Wiedergabe** | läuft auch, wenn ein Hörspiel oder Musik spielt; sonst nur, wenn die Box still ist |

- Ein Tipp beendet den Bildschirmschoner. Der Tipp löst dabei nichts anderes aus.
- Er endet von selbst, wenn das Display wie gewohnt ausschaltet (**Einstellungen › Display & Bedienung › Display**). Er hält das Display nicht länger an.
- Er zählt nicht als [Bildzeit](bildzeit.md). Er läuft nicht in Ruhezeiten und nicht, wenn die Bildzeit für heute um ist.
- Clips zeigt er nicht, nur Fotos.
