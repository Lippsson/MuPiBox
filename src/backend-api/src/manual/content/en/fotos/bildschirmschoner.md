# Screensaver

The screensaver shows a slideshow of the visible albums when nobody has used the box for a while. You switch it on under **Settings › Photos › Screensaver**.

| Setting | Effect |
| --- | --- |
| **Screensaver** | on or off |
| **Starts after** | after how many minutes without a touch (1 to 30, 5 at first) |
| **Also during playback** | also runs while an audio book or music plays; otherwise only while the box is silent |

- A tap ends the screensaver. The tap does nothing else.
- It ends by itself when the display switches off as usual (**Settings › Display & controls › Display**). It does not keep the display on longer.
- It does not count as [picture time](bildzeit.md). It does not run in quiet times, nor when the picture time is used up for today.
- It shows no clips, only photos.
