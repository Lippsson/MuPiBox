# iCloud (shared albums)

The box can show a **shared album** of the iPhone's Photos app when its **public website** is switched on. All the box needs is the link to the album, no Apple ID.

## Sharing the album on the iPhone

1. In **Photos**, open the shared album (or create a new one under **Albums › Shared Albums**).
2. Tap the **people icon** at the top and switch on **Public Website**.
3. Choose **Share Link** and send the link to yourself, by message for example.

The link looks like this: `https://photos.icloud.com/shared/album/…`. Anyone who knows it can see the album.

## Adding an album

Under **Library › Photos › Connect a photo service › iCloud**, paste the link into **Link to the album** and tap **Add album**. The box checks the link, takes over the album's name and starts the sync. Every shared album is a link of its own; up to 30 can be connected. The cross next to an album removes it from the box again.

| Message | What to do |
| --- | --- |
| not a link to a shared album | take the public website's link, it starts with `https://photos.icloud.com/shared/album/` |
| a link of the former kind | open the album on the iPhone and share the link again |
| no public album (any more) | check whether **Public Website** is still switched on |
| iCloud cannot be reached right now | check the box's internet connection |

The box takes the versions Apple provides for the web: photos of about 2048 pixels and videos as MP4. So videos are there **live too**. Whether the box keeps the photos or fetches them when shown is explained under [Photo services: keep or live](speichern-oder-live.md).

> [!NOTE]
> Apple offers no official interface for this. The box reads the album the way the public website does. If Apple changes something there, these albums may be **not there right now** for a while, until the box follows. The box does not read the name and e-mail address of the album's owner.
