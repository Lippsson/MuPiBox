# Extensions

Since MuPiBox 5.1 you can add **extensions**: extra functions that not every box needs. The box is complete without them. You install them, switch them on and off and remove them in the app under **Settings › System › Extensions**.

| Page | Content |
| --- | --- |
| [Installing and managing](installieren.md) | catalog, installing, switching on and off, removing, your own files |
| [Buttons & GPIO Input](buttons.md) | buttons on the GPIO pins control the box: short and long press, twin buttons |
| [USB CD drive](cd-laufwerk.md) | play audio CDs from a USB drive |
| [Time in the header](uhrzeit.md) | the time at the top of the display, digital or analog |
| [Weather](wetter.md) | the weather of a place as dials on the display |
| [Users](benutzer.md) | several users on one box, each with their own settings and library |
| [NFC reader](nfc.md) | an NFC reader (PN5180) on the SPI port reads tags: wiring, settings, status |

> [!WARNING]
> An extension is a program that runs on the box **without protection**. Only install extensions from the catalog or from sources you trust.
