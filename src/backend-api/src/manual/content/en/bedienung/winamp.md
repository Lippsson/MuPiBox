# The Winamp theme

The theme **Winamp** draws the player like the classic Winamp 2: with main window, equaliser and playlist, in the look of a **Winamp skin** (`.wsz`). You choose it like any theme under **Settings › Appearance › Theme** ([Covers and themes](cover-und-themes.md)).

## Skins

One skin comes with the theme, so there is something to see at once. While **Winamp** is the theme, the card **Winamp skin** is shown below the theme selection:

| Action | Effect |
| --- | --- |
| **Upload skin (.wsz)** | uploads a skin from your phone or PC to the box |
| **Tap on a skin in the list** | selects it; the display shows it at once |
| **Remove** | deletes a skin from the list |

All uploaded skins stay in the list, also when another theme is chosen in between. Skins to download are available in the **Winamp Skin Museum** (skins.webamp.org); the card links to it.

> [!NOTE]
> If there is no skin, the display says so and names the way in the app.

## The windows

On a **wide display** (1920 × 480) the **main window** is always on the left half. On the right you see the library, that is the usual pages of the box, or on top of it the **equaliser** or the **playlist**.

On a **smaller display** (for example 800 × 480) only one window is visible at a time: the player, the equaliser or the playlist. The header of the box stays above it. While the library is open, a small round button at the bottom left brings the player back.

## The main window

The main window shows the playing time, the title as a scrolling text, bit rate and sample rate, mono or stereo and the bars of the analyser. The analyser is decoration: it moves while something is playing but does not measure the sound.

| Control | Effect |
| --- | --- |
| **Five buttons** at the bottom left | previous track, play, pause, stop, next track |
| **Position bar** | seeks within the track |
| **Volume** and **balance** | the two sliders above the position bar |
| **Eject** | opens the library. With the extension [USB CD drive](../erweiterungen/cd-laufwerk.md) and a drive, it opens the drive's tray |
| **SHUFFLE** | shuffle, for albums of the library, the NAS and for Spotify music |
| **REPEAT** | repeat |
| **EQ** and **PL** | open and close the equaliser and the playlist |
| **Logo** at the left of the title bar | a small menu: library, playlist, equaliser, track info; below it is the name of the skin |

The labels of the windows and their menus are in English, as in the original.

## The equaliser

The equaliser has a pre-amp and **ten bands**, each from −12 to +12 dB.

| Control | Effect |
| --- | --- |
| **ON** | switches the equaliser on and off |
| **PRESETS** | load presets, save your own setting, delete one and set one as the default. Winamp's own presets are included |
| **AUTO** | when an album starts, loads the preset that was saved for that album |

The box remembers your own presets. The equaliser has no effect on **Spotify**; the window says so then.

## The playlist

The playlist window shows the tracks of what is playing. A tap on a track plays it. While tracks are selected, a tap selects or deselects further ones instead.

For albums of the **library** and the **NAS**, the buttons at the bottom edit the box's **queue**:

| Button | Effect |
| --- | --- |
| **ADD** | browse a folder of the library and add it (ADD DIR) |
| **REM** | remove the selected tracks (REM SEL), all but the selected ones (CROP) or all (REM ALL) |
| **SEL** | select all tracks, none, or invert the selection. You select a single track by holding it |
| **MISC** | the file info of a track (FILE INFO) and sorting: by title, file name or path, reversed or random |
| **LIST OPTS** | save the list (SAVE LIST), load a saved one (LOAD LIST) or start a new one (NEW LIST) |

This only changes the queue: no file is deleted or moved on the box or on the NAS. With Spotify, TIDAL and a CD the list cannot be edited.

## If something looks different than expected

- **The skin looks incomplete**: some skins do not bring all pictures. The box then draws simple replacements, for example for the knob of the position bar.
- **"That is not a Winamp skin (.wsz)"** when uploading: the file is not a classic skin for Winamp 2. Modern skins (`.wal`) do not work.
