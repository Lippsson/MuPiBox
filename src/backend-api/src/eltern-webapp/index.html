    Spotify-Setup

    Schritt 1 von 5

    Schritt 1 — Spotify-App anlegen

    Bevor MuPiBox mit Spotify reden kann, brauchen wir eine kleine „App" in deinem Spotify-Konto. Keine Sorge — das dauert keine 5 Minuten und kostet nichts.

    1. Öffne in einem neuen Tab: Spotify-Developer-Dashboard
    2. Logge dich mit deinem normalen Spotify-Konto ein.
    3. Klicke oben rechts auf Create app.

    Schritt 2 — Felder ausfüllen

    Trage in das Spotify-Formular ein:

    LeniBox
    MuPiBox Smart-Sync

    APIs/SDKs: ☑ Web API. Häkchen bei „I understand and agree" → Save.

    Schritt 3 — Client ID kopieren

    Klicke in deiner neuen App oben links auf Settings.

    Kopiere den Wert hinter „Client ID":

    Client Secret brauchst du nicht — bleibt geheim in deinem Spotify-Konto.

    Schritt 4 — Verbindung testen

    Wir öffnen jetzt die Spotify-Anmeldeseite. Du autorisierst die App, danach kommst du automatisch zurück.
